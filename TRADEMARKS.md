# Name and logo

The code of Oriel is free software (see `LICENSE` and `NOTICE`). Its **name and logo are not**.
They identify the official app made by khush2003, so people know what they're installing.

## You may, without asking

- Say your project is "based on Oriel" or a "fork of Oriel", and link to this repository. In
  fact you must give that credit (see `NOTICE`).
- Use the name "Oriel" to refer to this project in articles, reviews, videos and tutorials.
- Build Oriel unmodified from this repository for your own use.

## You may not, without written permission

- Publish a modified version, or any app, under the name "Oriel" or a confusingly similar
  name, or with the Oriel icon (three nested arcs around a dot) or something resembling it.
- Use the application ID `app.oriel`, or sign builds in a way that suggests they're official.
- Suggest that khush2003 made, endorses or supports your version.
- Use the name or logo in a store listing, domain name or social account that could be
  mistaken for the official project.

If you fork Oriel, choose your own name and icon and change the application ID. That's all that's needed.
